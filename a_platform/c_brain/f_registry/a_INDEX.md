# Registry do Brain

## Finalidade

O Registry mantém os catálogos e metadados necessários para localizar e controlar os recursos de conhecimento do Brain.

## Responsabilidades

O Registry poderá controlar:

- fontes de conhecimento;
- categorias;
- localização;
- versão;
- status;
- ciclo de vida;
- origem;
- escopo;
- relação com AAF Knowledge ou Project Knowledge.
