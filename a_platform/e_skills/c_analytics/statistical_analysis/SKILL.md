# Statistical Analysis Skill

## Purpose
Executar análise estatística rigorosa com computação de média, mediana, desvio padrão, assimetria, curtose, matriz de correlação e detecção de outliers.

## When to use
- Quando o projeto demandar quantificação estatística aprofundada de variáveis.

## When not to use
- Quando apenas contagens simples ou agregações SQL básicas forem requeridas.

## Inputs
- `task_description` (string, optional): Descrição das análises estatísticas necessárias.

## Outputs
- `statistical_analysis.py` (string): Código executável com as análises estatísticas.

## Capabilities
- statistical-analysis
- descriptive-statistics
- correlation-matrix
- hypothesis-testing
- outlier-detection

## Constraints
- Conclusões devem ser matematicamente sustentadas pelos dados.
