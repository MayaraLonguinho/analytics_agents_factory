# Data Visualization Skill

## Purpose
Gerar código de visualização gráfica de dados utilizando bibliotecas adequadas (Matplotlib, Seaborn ou Plotly), selecionando o tipo de gráfico mais adequado à natureza das variáveis.

## When to use
- Quando o usuário ou o plano requerer geração de gráficos ou relatórios visuais.

## When not to use
- Para projetos puramente headless/CLI sem demanda gráfica explícita.

## Inputs
- `task_description` (string, optional): Tipo de gráfico ou variáveis a plotar.

## Outputs
- `visualize.py` (string): Código executável de geração das visualizações.

## Capabilities
- data-visualization
- chart-generation
- visual-encoding
- plots-export

## Constraints
- Salvar imagens em formato estático (PNG/SVG) ou HTML conforme especificado.
