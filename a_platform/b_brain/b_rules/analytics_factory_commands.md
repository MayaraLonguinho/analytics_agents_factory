# Comandos do Analytics AI Factory

O adaptador Devin deve interagir com o Analytics AI Factory através de sua interface oficial.

## Domínios da Primeira Versão

Os domínios suportados são:

- Analytics;
- Data Engineering.

O adaptador não deve implementar a lógica principal do AAF.

## Comandos

```text
analytics execute
data_engineering execute
project create analytics
project create data_engineering
