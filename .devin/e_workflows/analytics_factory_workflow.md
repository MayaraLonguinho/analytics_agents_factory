# Workflow do Analytics AI Factory

Este workflow permite que o Devin encaminhe comandos do Analytics AI Factory a partir da interação com o usuário.

## Objetivo

O Devin atua como camada de integração.

A execução real ocorre no núcleo do Analytics AI Factory.

## Comandos da Primeira Versão

Os principais comandos relacionados aos domínios da primeira versão são:

```text
analytics execute
data_engineering execute
project create analytics
project create data_engineering
