# Adaptador Devin

Carregue automaticamente os componentes canônicos definidos em `INDEX.md`.

Este arquivo é uma configuração de integração do Devin com o Analytics AI Factory.

O adaptador Devin não contém:

- conhecimento canônico do AAF;
- regras canônicas do AAF;
- prompts canônicos do AAF;
- skills canônicas do AAF;
- lógica de negócio do AAF;
- lógica de geração de projetos;
- lógica de execução de projetos;
- lógica de validação;
- lógica de qualidade;
- lógica de certificação.

Essas responsabilidades pertencem ao núcleo do Analytics AI Factory.

O Devin atua somente como camada de integração e execução das interfaces disponibilizadas pelo AAF.
