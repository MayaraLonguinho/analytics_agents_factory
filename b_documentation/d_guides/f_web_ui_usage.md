# Guia de Uso: Web UI

**Nota Oficial:** A interface Web (UI) não está ativa na versão corrente do projeto Analytics AI Factory.

Para interagir com a plataforma, orientamos o uso exclusivo das seguintes interfaces oficiais suportadas pelo núcleo do AAF:
- **Interface Principal:** IDE Chat (veja `ide_chat_usage.md`)
- **Interface Secundária:** CLI (veja `cli_usage.md`)
